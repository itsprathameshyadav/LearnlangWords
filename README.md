# LearnLangWords

**Build your vocabulary, one word at a time.**

LearnLangWords is an AI-powered language-learning automation project that delivers daily vocabulary emails containing words, pronunciations, meanings, example sentences, and translations in the learner's preferred language.

The project combines Python, Google's Gemini API, Supabase, GitHub Actions, and a web dashboard to make language learning simple and consistent.

## ✨ Features

* Automated daily vocabulary emails
* AI-generated vocabulary using Google Gemini
* Support for eight languages
* Customizable daily vocabulary goals
* Word pronunciation, meaning, example, and translation
* Dashboard for today's and previously generated vocabulary
* Supabase database for storing learning settings and vocabulary
* GitHub Actions for scheduled automation

## ⚙️ Setup and Installation

Follow these steps to set up LearnLangWords from scratch.

### 1. Clone the Repository

Install Git and Python, then clone the project:

```bash
git clone https://github.com/itsprathameshyadav/LearnlangWords.git
cd LearnlangWords
```

### 2. Create a Supabase Project

Supabase is used to store the application's settings and generated vocabulary.

1. Visit [Supabase](https://supabase.com/).
2. Create an account or sign in.
3. Click **New Project**.
4. Enter a project name and configure a strong database password.
5. Select a region and create the project.
6. Wait for the database to finish provisioning.
7. Open the project's **SQL Editor**.

#### Create the Database Tables

Run the following SQL in the SQL Editor to create the tables used by the application:

```sql
CREATE TABLE IF NOT EXISTS public.settings (
    id BIGINT PRIMARY KEY DEFAULT 1 CHECK (id = 1),
    email TEXT NOT NULL DEFAULT '',
    language TEXT NOT NULL DEFAULT 'English',
    learn_in TEXT NOT NULL DEFAULT 'English',
    words_per_day INTEGER NOT NULL DEFAULT 1
        CHECK (words_per_day IN (1, 2, 3, 5, 10)),
    automation_started BOOLEAN NOT NULL DEFAULT FALSE
);

CREATE TABLE IF NOT EXISTS public.vocabulary (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    word TEXT NOT NULL,
    pronunciation TEXT,
    meaning TEXT NOT NULL,
    example TEXT,
    example_pronunciation TEXT,
    example_meaning TEXT,
    language TEXT NOT NULL,
    learn_in TEXT NOT NULL DEFAULT 'English',
    email_sent BOOLEAN NOT NULL DEFAULT FALSE,
    generated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

INSERT INTO public.settings (id)
VALUES (1)
ON CONFLICT (id) DO NOTHING;
```

This creates a single settings record and a vocabulary table that stores generated words and email delivery status.

#### Get Your Supabase Credentials

1. Open your Supabase project.
2. Navigate to **Connect** or **Settings → API Keys**, depending on the dashboard view.
3. Copy the project URL.
4. Copy the **publishable key** for the browser dashboard.
5. Obtain a suitable server-side key for the Python automation.

Use a publishable key in browser code only with appropriate Row Level Security (RLS) policies. Keep any secret or service-role key exclusively in trusted server-side environments. Supabase's [API key documentation](https://supabase.com/docs/guides/getting-started/api-keys) explains the distinction.

**Security note:** The current dashboard has no login system. Do not publish it with unrestricted anonymous read/write access to your settings or vocabulary tables. Configure appropriate access controls before deployment.

### 3. Get a Google Gemini API Key

Google Gemini generates the vocabulary content, meanings, pronunciations, and example sentences.

1. Visit [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your Google account.
3. Open the API Keys section.
4. Create an API key and select or create a Google Cloud project if prompted.
5. Copy the key and store it securely.
6. Use the key through the `GEMINI_API_KEY` environment variable.

Official instructions: [Gemini API Key Setup](https://ai.google.dev/gemini-api/docs/api-key).

The Python application uses the Google Gen AI SDK to communicate with Gemini.

### 4. Configure Gmail SMTP

Gmail SMTP is used to send vocabulary emails.

1. Sign in to the Google account that will send the emails.
2. Enable **2-Step Verification**.
3. Open the [Google Account App Passwords page](https://myaccount.google.com/apppasswords), if available for your account.
4. Generate an app password.
5. Save the app password securely.

Use your Gmail address as `SENDER_EMAIL` and the generated app password as `SENDER_APP_PASSWORD`.

Do not use your normal Google account password in the application. App passwords require 2-Step Verification and may not be available for every account. See [Google's App Password documentation](https://support.google.com/accounts/answer/185833).

### 5. Configure Environment Variables

Create a `.env` file in the project root for local development:

```env
GEMINI_API_KEY=your_gemini_api_key
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_server_side_supabase_key
SENDER_EMAIL=your_gmail_address
SENDER_APP_PASSWORD=your_gmail_app_password
```

Replace the placeholders with your actual credentials.

Install the required Python dependencies using the project's `requirements.txt` file:

```bash
pip install -r requirements.txt
```

If the file is not present, create one containing the libraries used by `main.py`:

```text
python-dotenv
google-genai
supabase
```

**Important:** Add `.env` to `.gitignore` and never commit it to GitHub. Use a server-side Supabase key for Python only if the code requires the permissions that key grants, and never place that key in `script.js`.

### 6. Configure GitHub Actions Secrets

GitHub Actions runs the vocabulary automation without requiring your computer to remain switched on.

1. Open your GitHub repository.
2. Navigate to **Settings → Secrets and variables → Actions**.
3. Click **New repository secret**.
4. Add each of the following secrets using the exact names:

| Secret name           | Value                    |
| --------------------- | ------------------------ |
| `GEMINI_API_KEY`      | Gemini API key           |
| `SUPABASE_URL`        | Supabase project URL     |
| `SUPABASE_KEY`        | Server-side Supabase key |
| `SENDER_EMAIL`        | Gmail sender address     |
| `SENDER_APP_PASSWORD` | Gmail app password       |

Use the same variable names in your Python script and GitHub Actions workflow.

Official instructions: [Using secrets in GitHub Actions](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets).

### 7. Configure the GitHub Actions Workflow

The workflow file belongs inside the `.github/workflows/` directory.

The workflow should:

1. Check out the repository.
2. Set up Python.
3. Install the dependencies from `requirements.txt`.
4. Make the configured secrets available as environment variables.
5. Execute `python main.py`.
6. Run on the configured schedule.

Ensure that GitHub Actions is enabled for the repository.

Open the **Actions** tab, select the LearnLangWords workflow, and use **Run workflow** if manual execution is enabled. Check the logs for errors.

For more information, see the [GitHub Actions workflow documentation](https://docs.github.com/en/actions).

### 8. Run the Automation Locally

After completing the setup, run:

```bash
python main.py
```

The program reads the settings from Supabase, generates vocabulary through Gemini, stores the generated data, and sends emails when they are due according to the configured schedule.

Make sure your environment variables, database tables, and email credentials are correct before running the automation.

### 9. Open the Web Dashboard

The dashboard uses `index.html`, `style.css`, and `script.js`.

To use it:

1. Open `script.js`.
2. Configure the Supabase project URL and publishable key.
3. Ensure the database access policies permit the intended dashboard operations.
4. Open `index.html` in a browser or deploy the static files using GitHub Pages.

Do not place Gemini API keys, Gmail app passwords, or Supabase secret keys in frontend JavaScript.

## 📧 Vocabulary Email Contents

Each vocabulary email can contain:

* **Word:** The selected vocabulary word
* **Pronunciation:** A pronunciation guide
* **Meaning:** The meaning in the selected explanation language
* **Example:** A sentence using the word
* **Example Pronunciation:** A pronunciation guide for the sentence
* **Example Meaning:** The translated example sentence

## 🔐 Security Considerations

* Keep API keys and email credentials private.
* Store automation credentials in GitHub Actions Secrets.
* Never expose server-side Supabase secret keys in browser code.
* Apply suitable RLS policies to protect database records.
* Avoid enabling public database writes without appropriate authentication and authorization.
